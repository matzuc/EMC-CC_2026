# Software necessario

Prima del laboratorio installare:

1. **Miniforge** (consigliato) oppure una distribuzione Conda già disponibile, come Miniconda o Anaconda. Miniforge è scaricabile dalla [pagina ufficiale](https://github.com/conda-forge/miniforge#download).
2. **Visual Studio Code**, scaricabile dal [sito ufficiale](https://code.visualstudio.com/Download).
3. **Panoply**, scaricabile dal [sito NASA](https://www.giss.nasa.gov/tools/panoply/download/). Panoply richiede Java 11 o una versione successiva.

Python e le librerie necessarie verranno installati nell'ambiente isolato descritto nella [guida alla configurazione](setup_python.md). Non è quindi necessario installare Python separatamente.

## Account necessari

Per scaricare i dati durante il laboratorio è necessario disporre di account gratuiti sui portali utilizzati:

- [Copernicus Marine Data Store](https://data.marine.copernicus.eu/register);
- [Copernicus Climate Data Store](https://cds.climate.copernicus.eu/).

Conservare le credenziali, ma non inserirle nei file del repository né condividerle con altre persone.
